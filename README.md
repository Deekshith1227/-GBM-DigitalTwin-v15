\# 🧠 GBM Digital Twin



\## AI-Powered Precision Oncology Platform for Glioblastoma Survival Prediction and Personalized Drug Recommendation



\---



\# Overview



GBM Digital Twin is an AI-driven precision oncology platform developed for Glioblastoma (GBM) patient analysis. The platform integrates clinical information and RNA-Seq gene expression data to predict patient survival, identify prognostic biomarkers, recommend personalized therapeutic drugs, and generate comprehensive clinical reports.



The project was developed as part of the M.Pharm (Pharmaceutical Biotechnology) research work and demonstrates the integration of bioinformatics, machine learning, and clinical decision support into a unified software platform.



\---



\# Key Features



\* Clinical Data Processing

\* RNA-Seq Gene Expression Analysis

\* Survival Risk Prediction

\* 1-Year, 3-Year and 5-Year Survival Estimation

\* Personalized Drug Recommendation

\* Drug Response Prediction

\* Biomarker Identification

\* Interactive Visualizations

\* Clinical PDF Report Generation

\* Streamlit-based User Interface
